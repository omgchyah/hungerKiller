# 🍽️ HungerKiller – Laravel CRUD App  
*My first full Laravel project built from scratch*

**HungerKiller** is a basic CRUD application developed with **Laravel**, using **MySQL** for the database and **Docker** for environment setup. It's my first hands-on project with Laravel, where I explored core backend development practices like routing, seeding, factories, and MVC structure.

## 🚀 Features

- Full CRUD functionality (create, read, update, delete)
- Database seeders and model factories
- RESTful routes using Laravel controllers
- Dockerized Laravel environment
- Clean MVC structure
- Modular and reusable Blade templates

## 🛠️ Tech Stack

- ⚙️ Laravel 10
- 🐬 MySQL (via Docker container)
- 🐳 Docker & Docker Compose
- 🧪 Seeders & Factories
- 🧩 Blade templates
- 🗄️ Artisan commands
